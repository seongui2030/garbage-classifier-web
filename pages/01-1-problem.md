
## 문제 상황

생활 속 쓰레기는 재질과 상태가 다양합니다. 같은 플라스틱이라도 투명병, 색이 있는 용기, 비닐은 모양이 다릅니다. 음식물이 묻은 종이는 재활용 가능 여부가 달라질 수 있습니다. 이 교재의 CNN은 행정적 재활용 판정을 대신하는 모델이 아니라, 사진 속 물체가 학습한 10개 시각 범주 중 어디에 가까운지 보여주는 교육용 모델입니다.

## 입력과 출력 정의

입력은 RGB 사진 한 장입니다. 사진은 중앙을 정사각형으로 자른 뒤 `180×180`으로 바꿉니다. 출력은 길이가 10인 확률 배열입니다.

```python
classes = [
    "battery", "cardboard", "clothes", "food", "glass",
    "metal", "paper", "plastic", "shoes", "trash"
]
```

예측 배열이 다음과 같다고 가정합니다.

```python
probabilities = [0.02, 0.01, 0.40, 0.00, 0.01,
                 0.35, 0.18, 0.01, 0.01, 0.01]
```

가장 큰 값은 `0.40`이므로 `clothes`가 1위입니다. 그러나 40%는 충분히 확신하기 어려운 값입니다. 2위 `metal`도 35%이므로 모델이 두 범주 사이에서 망설이고 있습니다.

```python
best_index = probabilities.index(max(probabilities))
print(classes[best_index])
```

## 성공 조건

- 사진 한 장을 선택할 수 있습니다.
- 모델 입력이 `(1, 180, 180, 3)`입니다.
- 가장 높은 클래스와 확률을 보여줍니다.
- 10개 클래스의 모든 확률을 높은 순서로 보여줍니다.
- 최고 확률이 60% 미만이면 재촬영 안내를 표시합니다.

## 한계 명시

모델이 학습하지 않은 도자기, 전자제품, 복합재료는 10개 중 하나로 억지로 분류될 수 있습니다. 따라서 웹앱에는 ‘판단이 불확실합니다’라는 안내가 필요합니다. 좋은 인공지능 앱은 자신 없는 상황을 숨기지 않습니다.
