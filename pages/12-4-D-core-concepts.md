
# 12-4. 핵심 용어 설명 모음

교사는 각 용어를 반드시 **일상생활 비유 → 정확한 컴퓨터과학적 정의 → 코드에서의 역할 → 직접 확인 → 오개념 바로잡기** 순서로 설명한다. 비유는 첫 문턱을 낮추는 도구일 뿐 정의를 대신하지 않는다. 실습 기준은 160×160 RGB, 6개 클래스, TensorFlow/Keras 4단계 핵심 CNN이다.

## 수업 활용 방법

1. 교사가 비유만 읽고 학생에게 용어의 의미를 예상하게 한다.
2. 정확한 정의를 읽은 뒤 비유와 다른 점에 밑줄을 긋는다.
3. 교재의 Colab 코드에서 해당 용어가 구현된 줄을 찾는다.
4. 직접 확인 활동으로 숫자·shape·그래프를 출력한다.
5. 마지막으로 오개념 문장을 올바른 문장으로 고쳐 쓴다.

## 1. 전처리 핵심 용어

### 픽셀(Pixel)

#### ① 일상생활 비유

모자이크 그림의 작은 색 타일 한 조각.

#### ② 정확한 컴퓨터과학적 정의

디지털 이미지를 구성하는 가장 작은 표본 단위다. RGB 이미지의 한 픽셀은 보통 빨강·초록·파랑 채널의 수치로 표현된다.

#### ③ 코드에서의 역할

`np.array(image)`로 이미지를 배열로 바꾸면 각 위치의 채널 값이 모델 입력이 된다.

#### ④ 직접 확인

`print(x.shape, x[0,0])`로 왼쪽 위 픽셀의 세 채널 값을 출력한다.

#### ⑤ 오개념 바로잡기

픽셀은 작은 사진 파일이 아니다. 픽셀은 이미지의 한 위치에 저장된 수치이며, 픽셀 하나만으로 물체의 의미를 알 수 없다.

### 해상도와 입력 크기

#### ① 일상생활 비유

서로 크기가 다른 사진을 같은 규격의 액자에 맞추기.

#### ② 정확한 컴퓨터과학적 정의

해상도는 이미지를 이루는 가로·세로 픽셀 수이고, 모델의 입력 크기는 신경망이 받도록 고정한 텐서의 공간 크기다. 이 교재에서는 160×160을 사용한다.

#### ③ 코드에서의 역할

`image_size=(160,160)`은 모든 이미지를 같은 텐서 모양으로 맞춰 한 배치로 계산하게 한다.

#### ④ 직접 확인

160과 224로 각각 불러와 `element_spec`과 학습 시간을 비교한다.

#### ⑤ 오개념 바로잡기

크기를 크게 만들면 원래 없던 세부 정보가 생기지 않는다. 작은 이미지를 확대하면 픽셀 수는 늘어도 실제 정보가 복원되는 것은 아니다.

### RGB 채널

#### ① 일상생활 비유

빨강·초록·파랑 투명 필름 세 장을 겹쳐 한 색을 만드는 것.

#### ② 정확한 컴퓨터과학적 정의

RGB 이미지는 각 픽셀을 Red, Green, Blue 세 성분으로 표현하므로 텐서의 마지막 축 크기가 3이다.

#### ③ 코드에서의 역할

입력 모양 `(160,160,3)`의 3은 색상 채널 수이며 Conv2D 필터는 세 채널을 함께 계산한다.

#### ④ 직접 확인

`print(images.shape)`를 실행해 `(배치,160,160,3)`인지 확인한다.

#### ⑤ 오개념 바로잡기

채널은 클래스가 아니다. RGB 채널 3개와 분류 라벨 6개는 서로 다른 축과 목적을 가진다.

### 텐서(Tensor)

#### ① 일상생활 비유

숫자를 칸에 정리한 다층 서랍장.

#### ② 정확한 컴퓨터과학적 정의

텐서는 동일한 자료형의 수치를 여러 차원 축으로 배열한 자료구조이며, 딥러닝 연산의 기본 입력과 출력이다. 이미지 배치는 보통 4차원 텐서다.

#### ③ 코드에서의 역할

모델은 `(batch,height,width,channel)` 텐서를 층마다 변환한다.

#### ④ 직접 확인

`tf.rank(images)`와 `images.shape`로 차원 수와 각 축의 크기를 출력한다.

#### ⑤ 오개념 바로잡기

텐서는 어려운 이름의 리스트일 뿐이라고만 보면 부족하다. GPU에서 미분 가능한 연산을 효율적으로 수행하도록 설계된 수치 구조다.

### 라벨(Label)과 클래스(Class)

#### ① 일상생활 비유

사진 상자에 붙인 정답 이름표와 이름표의 전체 종류.

#### ② 정확한 컴퓨터과학적 정의

클래스는 모델이 구별할 범주의 집합이고 라벨은 각 데이터에 부여된 정답 클래스의 표현이다. 정수 라벨은 클래스 인덱스를 사용한다.

#### ③ 코드에서의 역할

폴더명이 `class_names`가 되고 각 이미지는 그 순서에 해당하는 정수 라벨을 받는다.

#### ④ 직접 확인

첫 배치의 `labels[:10]`과 `class_names`를 함께 출력해 정수와 이름을 연결한다.

#### ⑤ 오개념 바로잡기

정수 0이 플라스틱이라는 뜻은 고정 규칙이 아니다. 실제 의미는 `class_names`의 순서로 결정되며 학습과 웹앱에서 같은 순서를 써야 한다.

### 정규화(Normalization)

#### ① 일상생활 비유

서로 다른 단위의 눈금을 일정한 범위로 맞추기.

#### ② 정확한 컴퓨터과학적 정의

정규화는 입력 수치의 범위나 분포를 학습에 적합하도록 변환하는 과정이다. 여기서는 0~255 픽셀 값을 255로 나누어 0~1로 만든다.

#### ③ 코드에서의 역할

`layers.Rescaling(1./255)`가 큰 픽셀 값을 줄여 최적화가 안정적으로 진행되도록 돕는다.

#### ④ 직접 확인

정규화 전후 `tf.reduce_min`과 `tf.reduce_max`를 비교한다.

#### ⑤ 오개념 바로잡기

정규화는 사진의 해상도를 바꾸는 것이 아니며, 모든 사진을 똑같은 색으로 만드는 것도 아니다. 수치의 척도를 바꾼다.

### 배치(Batch)

#### ① 일상생활 비유

학생 1명씩이 아니라 한 모둠씩 출석을 확인하기.

#### ② 정확한 컴퓨터과학적 정의

배치는 한 번의 순전파와 역전파에서 동시에 처리하는 데이터 샘플의 묶음이다. 배치 크기는 묶음에 포함되는 샘플 수다.

#### ③ 코드에서의 역할

`batch_size=32`이면 최대 32장의 이미지로 손실과 기울기를 계산해 한 번 가중치를 갱신한다.

#### ④ 직접 확인

`for images,labels in train_ds.take(1)`에서 첫 축의 크기를 확인한다.

#### ⑤ 오개념 바로잡기

배치 크기가 크다고 항상 정확도가 높아지는 것은 아니다. 메모리, 속도, 기울기의 변동성 사이의 절충값이다.

### 훈련·검증·테스트 분할

#### ① 일상생활 비유

문제집으로 공부하고 모의고사로 조정한 뒤 처음 보는 본시험을 치르기.

#### ② 정확한 컴퓨터과학적 정의

훈련 세트는 가중치 학습, 검증 세트는 설정 선택과 조기 종료, 테스트 세트는 최종 일반화 성능 추정에 사용하는 서로 겹치지 않는 데이터 집합이다.

#### ③ 코드에서의 역할

`validation_split`으로 훈련과 검증을 나누고 최종 시험용 데이터는 모델 선택이 끝날 때까지 보지 않는다.

#### ④ 직접 확인

각 세트의 파일 경로 교집합이 빈 집합인지 확인한다.

#### ⑤ 오개념 바로잡기

검증 데이터는 학습에 직접 사용하지 않지만 반복해서 설정을 고르면 간접적으로 맞춰질 수 있다. 그래서 별도 테스트 세트가 필요하다.

### 데이터 증강(Data Augmentation)

#### ① 일상생활 비유

같은 물건을 다른 각도와 밝기에서 다시 보는 연습.

#### ② 정확한 컴퓨터과학적 정의

데이터 증강은 기존 샘플에 라벨을 보존하는 변환을 무작위로 적용하여 예상되는 입력 변화를 모사하는 정규화 기법이다.

#### ③ 코드에서의 역할

`RandomFlip`, `RandomRotation`, `RandomZoom`은 훈련 중에만 서로 다른 변형을 만들어 특정 위치와 배경에 대한 의존을 줄인다.

#### ④ 직접 확인

같은 이미지에 `augment(x, training=True)`를 여러 번 적용해 결과를 나란히 그린다.

#### ⑤ 오개념 바로잡기

증강은 현실에서 수집한 새로운 물체 정보와 같지 않다. 잘못된 회전이나 뒤집기는 오히려 라벨 의미를 훼손할 수 있다.

## 2. 4단계 CNN 핵심 용어

### 합성곱(Convolution)

#### ① 일상생활 비유

작은 돋보기를 사진 위에서 조금씩 옮기며 무늬를 찾기.

#### ② 정확한 컴퓨터과학적 정의

합성곱 층은 학습 가능한 커널을 입력의 국소 영역에 공유 적용하여 위치별 가중합을 계산하고 특성 맵을 만드는 연산이다.

#### ③ 코드에서의 역할

`Conv2D(32,3)`은 3×3 커널 32개를 학습해 선, 색 대비, 질감에 반응하는 32개 특성 맵을 만든다.

#### ④ 직접 확인

학습 전후 첫 Conv2D 커널의 모양과 일부 값을 출력한다.

#### ⑤ 오개념 바로잡기

합성곱 필터는 사람이 미리 정한 가장자리 공식만 쓰는 것이 아니다. 이 모델에서는 손실을 줄이는 방향으로 필터 값이 학습된다.

### 커널·필터(Kernel/Filter)

#### ① 일상생활 비유

특정 무늬를 찾는 작은 도장.

#### ② 정확한 컴퓨터과학적 정의

커널은 입력의 국소 영역과 곱해지는 학습 가능한 가중치 배열이다. 딥러닝 문맥에서 필터는 한 출력 채널을 만드는 커널 묶음을 가리키기도 한다.

#### ③ 코드에서의 역할

`kernel_size=3`은 3×3 공간 범위를 보고, 필터 수 32는 출력 채널 수를 결정한다.

#### ④ 직접 확인

`model.layers[1].kernel.shape`처럼 해당 층의 커널 텐서 모양을 확인한다.

#### ⑤ 오개념 바로잡기

3×3은 픽셀 아홉 개만 본다는 뜻으로 끝나지 않는다. 층이 쌓이면 유효 수용 영역이 넓어져 더 큰 모양을 표현한다.

### 특성 맵(Feature Map)

#### ① 일상생활 비유

금속의 반짝임이 강한 위치만 표시한 투명 지도.

#### ② 정확한 컴퓨터과학적 정의

특성 맵은 필터가 입력의 각 위치에서 특정 패턴에 얼마나 반응했는지를 담은 출력 텐서의 채널이다.

#### ③ 코드에서의 역할

첫 단계는 단순 특징, 뒤 단계는 그 특징을 조합한 복잡한 패턴을 표현한다.

#### ④ 직접 확인

중간 출력을 반환하는 모델을 만들어 한 이미지의 특성 맵 몇 장을 시각화한다.

#### ⑤ 오개념 바로잡기

특성 맵 한 장이 반드시 사람이 이름 붙일 수 있는 한 개념과 일대일 대응하지는 않는다.

### 스트라이드(Stride)

#### ① 일상생활 비유

돋보기를 한 칸씩 또는 두 칸씩 옮기기.

#### ② 정확한 컴퓨터과학적 정의

스트라이드는 합성곱이나 풀링 창이 입력 위에서 이동하는 간격이다. 값이 커질수록 출력 공간 크기와 계산량이 줄어든다.

#### ③ 코드에서의 역할

기본 `strides=(1,1)`은 한 픽셀씩 이동하고 MaxPooling2D의 기본 보폭 2는 가로·세로를 대략 절반으로 줄인다.

#### ④ 직접 확인

같은 입력에 stride 1과 2를 적용해 출력 shape를 비교한다.

#### ⑤ 오개념 바로잡기

스트라이드를 크게 하면 중요한 정보만 자동으로 남는 것이 아니다. 위치 정보를 건너뛰어 작은 물체를 놓칠 수도 있다.

### 패딩(Padding)

#### ① 일상생활 비유

도장을 가장자리까지 찍기 위해 사진 둘레에 임시 여백을 두기.

#### ② 정확한 컴퓨터과학적 정의

패딩은 합성곱 전에 입력 경계 주변에 값을 추가하여 출력 크기와 경계 정보 처리 방식을 조절하는 연산이다. `same`은 stride 1일 때 공간 크기를 유지한다.

#### ③ 코드에서의 역할

`padding="same"`으로 가장자리 특징을 포함하면서 각 합성곱 뒤의 가로·세로 크기를 유지한다.

#### ④ 직접 확인

`valid`와 `same` 모델의 `output_shape`를 비교한다.

#### ⑤ 오개념 바로잡기

패딩은 실제 사진 내용을 새로 만들어 붙이는 것이 아니다. 주로 0 같은 규칙적 값을 계산용 경계로 추가한다.

### ReLU 활성화 함수

#### ① 일상생활 비유

음수 신호는 닫고 양수 신호는 통과시키는 간단한 문.

#### ② 정확한 컴퓨터과학적 정의

ReLU는 `f(x)=max(0,x)`로 정의되는 비선형 활성화 함수다. 비선형성을 추가해 여러 층이 복잡한 함수를 표현하게 한다.

#### ③ 코드에서의 역할

`activation="relu"`가 합성곱 결과의 음수를 0으로 바꾸고 양수는 유지한다.

#### ④ 직접 확인

`tf.nn.relu([-2.,0.,3.])`의 결과를 직접 출력한다.

#### ⑤ 오개념 바로잡기

ReLU가 중요하지 않은 특징을 정확히 판별해 지우는 것은 아니다. 단지 수학 규칙에 따라 음수 활성값을 0으로 만든다.

### 최대 풀링(Max Pooling)

#### ① 일상생활 비유

작은 구역에서 가장 강한 신호 하나만 대표로 적기.

#### ② 정확한 컴퓨터과학적 정의

최대 풀링은 각 국소 창의 최댓값을 선택해 특성 맵의 공간 크기를 축소하는 고정 연산이다. 학습되는 가중치는 없다.

#### ③ 코드에서의 역할

`MaxPooling2D()`가 계산량을 줄이고 작은 위치 변화에 덜 민감하도록 돕는다.

#### ④ 직접 확인

2×2 숫자 배열에서 최댓값을 손으로 고른 뒤 TensorFlow 결과와 비교한다.

#### ⑤ 오개념 바로잡기

풀링이 항상 잡음만 제거하는 것은 아니다. 작은 물체의 중요한 약한 신호도 사라질 수 있다.

### 전역 평균 풀링(Global Average Pooling)

#### ① 일상생활 비유

각 특징 지도 전체의 평균 점수를 한 칸 성적표로 줄이기.

#### ② 정확한 컴퓨터과학적 정의

각 특성 맵의 모든 공간 위치를 평균하여 채널당 하나의 값으로 바꾸는 연산이다.

#### ③ 코드에서의 역할

`GlobalAveragePooling2D()`가 `(높이,너비,채널)`을 `(채널)` 벡터로 바꾸어 Dense 층에 전달한다.

#### ④ 직접 확인

층 앞뒤의 출력 shape와 파라미터 수를 확인한다.

#### ⑤ 오개념 바로잡기

Flatten과 같은 결과를 만드는 것이 아니다. Flatten은 모든 위치 값을 펼치지만 전역 평균 풀링은 채널별 평균으로 강하게 요약한다.

### Dense와 Softmax

#### ① 일상생활 비유

여러 심사위원 점수를 여섯 후보의 최종 지지율로 바꾸기.

#### ② 정확한 컴퓨터과학적 정의

Dense 층은 모든 입력 특징의 가중합을 계산하며, Softmax는 로짓을 합이 1인 양의 확률 분포로 변환한다.

#### ③ 코드에서의 역할

`Dense(6, activation="softmax")`가 여섯 클래스 확률을 출력한다.

#### ④ 직접 확인

한 이미지의 출력 합이 약 1인지 `tf.reduce_sum(pred)`로 확인한다.

#### ⑤ 오개념 바로잡기

Softmax 90%는 현실에서 반드시 90% 맞는다는 보장이 아니다. 모델 확률은 보정되지 않았거나 낯선 입력에서 과신할 수 있다.

<a id="training"></a>

## 3. 학습 핵심 용어

### 순전파(Forward Pass)

#### ① 일상생활 비유

재료가 조리 공정을 차례로 지나 최종 음식이 나오기.

#### ② 정확한 컴퓨터과학적 정의

순전파는 입력이 현재 가중치를 사용하여 각 층의 연산을 순서대로 통과하고 예측과 손실을 계산하는 과정이다.

#### ③ 코드에서의 역할

`model(images, training=True)`가 현재 모델의 클래스 확률을 계산한다.

#### ④ 직접 확인

훈련 전 한 배치를 넣어 출력 shape가 `(배치,6)`인지 확인한다.

#### ⑤ 오개념 바로잡기

순전파만으로 가중치가 바뀌지 않는다. 가중치 갱신에는 손실의 기울기 계산과 옵티마이저 단계가 필요하다.

### 손실 함수(Loss Function)

#### ① 일상생활 비유

정답에서 얼마나 벗어났는지 나타내는 벌점표.

#### ② 정확한 컴퓨터과학적 정의

손실 함수는 예측과 정답의 불일치를 학습 가능한 하나의 스칼라 값으로 측정하는 함수다. 분류에서는 교차 엔트로피를 주로 쓴다.

#### ③ 코드에서의 역할

정수 라벨과 Softmax 출력에는 `sparse_categorical_crossentropy`를 사용한다.

#### ④ 직접 확인

정답 클래스 확률을 0.9와 0.1로 가정해 각각의 교차 엔트로피를 계산한다.

#### ⑤ 오개념 바로잡기

손실과 정확도는 같은 값이 아니다. 정확도가 같아도 정답 클래스에 준 확률에 따라 손실이 달라진다.

### 역전파(Backpropagation)

#### ① 일상생활 비유

결과가 나빴을 때 공정별 책임 신호를 뒤에서 앞으로 전달하기.

#### ② 정확한 컴퓨터과학적 정의

역전파는 연쇄 법칙을 이용해 손실을 각 학습 가능한 파라미터로 미분하는 효율적인 알고리즘이다.

#### ③ 코드에서의 역할

TensorFlow 자동 미분이 각 커널과 편향에 대한 기울기를 계산한다.

#### ④ 직접 확인

`tf.GradientTape`로 작은 Dense 층의 기울기 모양과 값 일부를 출력한다.

#### ⑤ 오개념 바로잡기

역전파는 데이터를 거꾸로 재생하는 과정이 아니다. 계산 그래프를 따라 미분값을 뒤쪽 층에서 앞쪽 층으로 전파한다.

### 가중치와 편향

#### ① 일상생활 비유

여러 단서에 서로 다른 중요도를 주고 기본 점수를 더하기.

#### ② 정확한 컴퓨터과학적 정의

가중치는 입력 특징의 영향력을 조절하는 학습 파라미터이고, 편향은 입력과 독립적으로 더해지는 학습 파라미터다.

#### ③ 코드에서의 역할

옵티마이저가 손실의 기울기를 이용해 Conv2D와 Dense의 가중치·편향을 갱신한다.

#### ④ 직접 확인

학습 전후 같은 가중치 원소를 저장해 값이 변했는지 비교한다.

#### ⑤ 오개념 바로잡기

가중치가 크면 무조건 중요한 특징이라는 단순 해석은 위험하다. 입력 척도와 다른 가중치의 상호작용을 함께 보아야 한다.

### 옵티마이저 Adam

#### ① 일상생활 비유

안개 속에서 내리막 방향과 최근 이동 흐름을 함께 참고해 걷기.

#### ② 정확한 컴퓨터과학적 정의

옵티마이저는 기울기를 사용해 파라미터 갱신량을 정하는 알고리즘이다. Adam은 기울기의 1차·2차 모멘트 이동평균을 이용해 파라미터별 적응적 학습률을 적용한다.

#### ③ 코드에서의 역할

`Adam(1e-3)`이 역전파로 얻은 기울기를 바탕으로 가중치를 갱신한다.

#### ④ 직접 확인

학습률 `1e-2`, `1e-3`, `1e-4`의 초기 손실 변화를 같은 조건에서 비교한다.

#### ⑤ 오개념 바로잡기

Adam이 언제나 가장 좋은 옵티마이저라는 뜻은 아니다. 데이터와 모델에 따라 다른 설정이 더 나을 수 있다.

### 학습률(Learning Rate)

#### ① 일상생활 비유

내리막길에서 한 걸음의 크기.

#### ② 정확한 컴퓨터과학적 정의

학습률은 옵티마이저가 기울기를 이용해 파라미터를 갱신하는 규모를 조절하는 하이퍼파라미터다.

#### ③ 코드에서의 역할

너무 크면 최솟값을 지나치며 불안정하고, 너무 작으면 학습이 느리거나 좋지 않은 지점에 머물 수 있다.

#### ④ 직접 확인

세 학습률의 loss 그래프를 같은 축에 그린다.

#### ⑤ 오개념 바로잡기

학습률은 모델이 외우는 속도와 정확히 같은 말이 아니다. 파라미터 갱신 크기에 영향을 주는 설정이다.

### 에포크와 스텝

#### ① 일상생활 비유

교과서를 처음부터 끝까지 한 번 공부하기와 문제 묶음 한 번 풀기.

#### ② 정확한 컴퓨터과학적 정의

에포크는 훈련 세트 전체를 한 번 사용한 주기이고, 스텝은 한 배치를 처리하고 보통 한 번 파라미터를 갱신하는 단위다.

#### ③ 코드에서의 역할

`model.fit(..., epochs=20)`은 최대 20회 전체 훈련 세트를 반복한다.

#### ④ 직접 확인

데이터 수와 배치 크기로 `ceil(N/BATCH)`를 계산해 실제 steps와 비교한다.

#### ⑤ 오개념 바로잡기

에포크를 늘리면 무조건 성능이 좋아지지 않는다. 검증 성능은 어느 시점 이후 나빠질 수 있다.

### 조기 종료(Early Stopping)

#### ① 일상생활 비유

연습을 계속해 모의고사 점수가 나빠지기 시작하면 가장 좋았던 상태로 돌아가기.

#### ② 정확한 컴퓨터과학적 정의

조기 종료는 검증 지표가 정해진 기간 개선되지 않을 때 학습을 멈추는 정규화 방법이다.

#### ③ 코드에서의 역할

`monitor="val_loss"`, `patience=4`, `restore_best_weights=True`로 과대적합과 불필요한 계산을 줄인다.

#### ④ 직접 확인

학습이 멈춘 epoch와 최소 val_loss epoch가 같은지 history로 확인한다.

#### ⑤ 오개념 바로잡기

조기 종료는 테스트 세트를 보며 멈추는 것이 아니다. 검증 세트를 사용해야 최종 테스트 평가의 공정성을 지킬 수 있다.

<a id="confusion-matrix"></a>

## 4. 혼동행렬 평가 핵심 용어

### 혼동행렬(Confusion Matrix)

#### ① 일상생활 비유

정답표의 행과 모델 답안의 열을 교차해 오답 유형을 세는 표.

#### ② 정확한 컴퓨터과학적 정의

혼동행렬은 실제 클래스와 예측 클래스 조합별 표본 수를 기록한 행렬이다. 이 교재에서는 행이 실제, 열이 예측이다.

#### ③ 코드에서의 역할

대각선은 맞힌 수, 대각선 밖은 어떤 클래스를 무엇으로 혼동했는지 보여 준다.

#### ④ 직접 확인

작은 `y_true`, `y_pred`를 손으로 세고 `confusion_matrix` 결과와 비교한다.

#### ⑤ 오개념 바로잡기

혼동행렬의 행과 열 방향은 도구에 따라 표시가 달라질 수 있다. 축 라벨을 확인하지 않고 해석하면 안 된다.

### 정확도(Accuracy)

#### ① 일상생활 비유

전체 시험 문제 중 맞힌 문제의 비율.

#### ② 정확한 컴퓨터과학적 정의

정확도는 전체 표본 수에 대한 올바른 예측 수의 비율이다. 다중 분류에서는 혼동행렬 대각선 합을 전체 합으로 나눈다.

#### ③ 코드에서의 역할

`metrics=["accuracy"]`와 테스트 평가에서 전체 맞힌 비율을 계산한다.

#### ④ 직접 확인

혼동행렬 대각선 합으로 정확도를 다시 계산해 모델 출력과 비교한다.

#### ⑤ 오개념 바로잡기

클래스 불균형이 크면 정확도가 높아도 적은 클래스는 거의 못 맞힐 수 있다.

### 정밀도(Precision)

#### ① 일상생활 비유

캔이라고 골라낸 것 중 실제 캔의 비율.

#### ② 정확한 컴퓨터과학적 정의

특정 클래스의 정밀도는 그 클래스로 예측한 표본 중 실제로 그 클래스인 비율로 `TP/(TP+FP)`다.

#### ③ 코드에서의 역할

오염된 분리배출을 줄이려면 특정 클래스 예측의 정밀도가 중요할 수 있다.

#### ④ 직접 확인

한 클래스를 양성으로 정하고 혼동행렬에서 TP와 FP를 찾아 계산한다.

#### ⑤ 오개념 바로잡기

정밀도는 실제 해당 클래스 전체를 얼마나 찾았는지 나타내지 않는다. 그것은 재현율이다.

### 재현율(Recall)

#### ① 일상생활 비유

실제 캔 전체 중 모델이 캔으로 찾아낸 비율.

#### ② 정확한 컴퓨터과학적 정의

특정 클래스의 재현율은 실제 그 클래스인 표본 중 올바르게 찾아낸 비율로 `TP/(TP+FN)`다.

#### ③ 코드에서의 역할

놓치면 위험하거나 비용이 큰 클래스는 재현율을 중요하게 볼 수 있다.

#### ④ 직접 확인

혼동행렬의 실제 클래스 행에서 TP와 FN을 찾아 계산한다.

#### ⑤ 오개념 바로잡기

재현율만 높이려고 모두 한 클래스로 예측하면 정밀도가 크게 떨어질 수 있다.

### F1 점수와 Macro-F1

#### ① 일상생활 비유

정밀도와 재현율 두 과목을 어느 한쪽에 치우치지 않게 종합하기.

#### ② 정확한 컴퓨터과학적 정의

F1은 정밀도와 재현율의 조화평균이고, Macro-F1은 각 클래스 F1을 동일한 비중으로 평균한 값이다.

#### ③ 코드에서의 역할

데이터 수가 적은 클래스도 같은 비중으로 보아 6종 분류의 균형을 확인한다.

#### ④ 직접 확인

`classification_report`의 클래스별 F1과 macro avg를 직접 평균해 비교한다.

#### ⑤ 오개념 바로잡기

F1이 높다고 확률 보정이나 모든 실생활 비용까지 좋은 것은 아니다. 목적에 맞는 지표를 함께 선택해야 한다.

### TP·FP·FN·TN

#### ① 일상생활 비유

화재 경보가 맞게 울림·잘못 울림·놓침·조용히 맞음.

#### ② 정확한 컴퓨터과학적 정의

한 클래스를 양성으로 정했을 때 TP는 맞게 양성, FP는 잘못 양성, FN은 놓친 양성, TN은 맞게 음성으로 분류한 수다.

#### ③ 코드에서의 역할

정밀도와 재현율 등 클래스별 지표 계산의 기초가 된다.

#### ④ 직접 확인

glass 한 클래스를 양성으로 정하고 6×6 혼동행렬에서 네 값을 합산한다.

#### ⑤ 오개념 바로잡기

다중 분류에서도 네 값은 한 클래스를 나머지 전체와 비교하는 one-vs-rest 관점으로 계산한다.

<a id="generalization"></a>

## 5. 일반화 핵심 용어

### 일반화(Generalization)

#### ① 일상생활 비유

연습 문제의 숫자가 바뀌어도 같은 원리로 새 문제 풀기.

#### ② 정확한 컴퓨터과학적 정의

일반화는 훈련에 사용하지 않은 동일한 목표 분포의 데이터에서 모델이 유용한 성능을 내는 능력이다.

#### ③ 코드에서의 역할

검증·테스트 사진과 실제 스마트폰 사진으로 성능을 확인한다.

#### ④ 직접 확인

배경·조명·거리만 바꾼 같은 물체 사진의 예측을 비교한다.

#### ⑤ 오개념 바로잡기

훈련 정확도가 높다는 사실만으로 일반화가 좋다고 말할 수 없다.

### 과대적합(Overfitting)

#### ① 일상생활 비유

문제와 답의 위치를 외워 숫자만 바뀐 문제를 못 푸는 상태.

#### ② 정확한 컴퓨터과학적 정의

과대적합은 모델이 훈련 데이터의 우연한 패턴과 잡음까지 맞춰 훈련 성능은 높지만 보지 않은 데이터 성능이 낮아지는 현상이다.

#### ③ 코드에서의 역할

훈련 loss는 감소하는데 val_loss가 증가하면 과대적합 신호로 본다.

#### ④ 직접 확인

두 loss 곡선의 벌어지는 시점과 가장 낮은 val_loss epoch를 표시한다.

#### ⑤ 오개념 바로잡기

훈련 정확도 100% 자체가 항상 과대적합의 증거는 아니다. 반드시 검증·테스트 성능과 차이를 함께 보아야 한다.

### 과소적합(Underfitting)

#### ① 일상생활 비유

연습도 충분히 하지 못해 문제집과 시험을 모두 못 푸는 상태.

#### ② 정확한 컴퓨터과학적 정의

과소적합은 모델의 표현력, 학습 시간, 특징 또는 최적화가 부족해 훈련 데이터에서도 패턴을 충분히 학습하지 못한 상태다.

#### ③ 코드에서의 역할

훈련과 검증 성능이 모두 낮으면 층, 필터 수, epoch, 학습률, 데이터 품질을 점검한다.

#### ④ 직접 확인

초기 몇 epoch와 충분히 학습한 결과의 train/val 지표를 비교한다.

#### ⑤ 오개념 바로잡기

훈련과 검증 점수가 비슷하다고 무조건 좋은 것이 아니다. 둘 다 낮으면 과소적합일 수 있다.

### Dropout

#### ① 일상생활 비유

모둠 연습 때 일부 학생을 무작위로 쉬게 해 특정 학생에게만 의존하지 않기.

#### ② 정확한 컴퓨터과학적 정의

Dropout은 훈련 중 일정 비율의 활성값을 무작위로 0으로 만들고 나머지를 조정하여 공동 적응을 줄이는 정규화 방법이다. 추론 때는 비활성화된다.

#### ③ 코드에서의 역할

`Dropout(0.2)`는 훈련 중 활성값의 20%를 확률적으로 제거한다.

#### ④ 직접 확인

같은 입력을 `training=True`와 `False`로 여러 번 통과시켜 출력 변동을 비교한다.

#### ⑤ 오개념 바로잡기

모델의 뉴런이나 가중치를 영구 삭제하는 것이 아니다. 훈련 단계에서만 무작위 마스크를 적용한다.

### 데이터 누수(Data Leakage)

#### ① 일상생활 비유

본시험 답을 연습 문제에 몰래 섞어 높은 점수를 얻기.

#### ② 정확한 컴퓨터과학적 정의

데이터 누수는 예측 시 사용할 수 없거나 평가 집합에 속한 정보가 훈련·전처리·모델 선택 과정에 들어가 성능 추정을 부당하게 높이는 현상이다.

#### ③ 코드에서의 역할

같은 사진의 복사본이나 증강본이 훈련과 검증에 나뉘지 않게 원본 기준으로 먼저 분할한다.

#### ④ 직접 확인

파일 해시와 원본 그룹 ID로 세트 간 중복을 검사한다.

#### ⑤ 오개념 바로잡기

누수는 라벨 열을 입력에 넣는 경우만 뜻하지 않는다. 같은 물체의 거의 동일한 연속 사진이 양쪽 세트에 들어가는 것도 누수 위험이다.

### 분포 이동(Dataset Shift)

#### ① 일상생활 비유

학교 체육관에서만 연습하다 야외 경기장에서 경기하기.

#### ② 정확한 컴퓨터과학적 정의

분포 이동은 학습 데이터와 실제 사용 데이터의 입력 또는 입력-정답 관계 분포가 달라지는 현상이다.

#### ③ 코드에서의 역할

Kaggle 사진과 스마트폰 사진의 배경, 카메라, 조명 차이가 예측 성능을 낮출 수 있다.

#### ④ 직접 확인

두 데이터 집합의 밝기·크기·클래스 비율과 실제 예측 지표를 비교한다.

#### ⑤ 오개념 바로잡기

데이터 증강만으로 모든 실제 환경 차이가 해결되지는 않는다. 대표성 있는 실제 데이터를 수집하고 사람 검토를 거쳐야 한다.

### 신뢰도와 사람의 확인

#### ① 일상생활 비유

낯선 문제에서 확신이 낮으면 선생님에게 확인받기.

#### ② 정확한 컴퓨터과학적 정의

신뢰도는 모델 출력 확률 중 선택한 클래스의 값이지만, 실제 정답 확률과 일치하려면 별도의 확률 보정과 검증이 필요하다.

#### ③ 코드에서의 역할

최댓값이 기준보다 낮거나 상위 두 클래스가 비슷하면 “확인 필요”로 표시한다.

#### ④ 직접 확인

정답 여부별 최대 Softmax 값의 히스토그램을 비교한다.

#### ⑤ 오개념 바로잡기

높은 신뢰도는 정답 보증서가 아니다. 분포 밖 이미지에서 모델은 틀리면서도 매우 높은 값을 낼 수 있다.
