## 확인 문제 지도 원칙

서술형은 단어 하나보다 이유와 근거를 본다. 예를 들어 과대적합 문항은 ‘훈련 정확도는 계속 높아지지만 검증 손실은 증가한다’는 두 지표의 관계를 설명하면 충분하다. 이미지 크기 문항은 크기가 커질수록 세부 정보가 늘 수 있으나 메모리와 계산 시간이 증가한다는 장단점을 함께 쓰게 한다. 실생활 문항은 지역 규정 확인, 신뢰도가 낮을 때 사람에게 질문, 개인정보 보호 가운데 두 가지 이상을 제시하도록 지도한다.

## 동료 평가 질문

1. 모델이 어떤 조건에서 실패하는가?
2. 성능 개선 실험에서 한 번에 하나의 조건만 바꾸었는가?
3. 클래스별 데이터 수와 지표를 공개했는가?
4. 다른 사람이 같은 결과를 재현할 정보가 있는가?
5. 실제 사용자가 오판을 바로잡을 방법이 있는가?
