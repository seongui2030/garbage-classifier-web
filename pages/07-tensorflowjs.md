
브라우저는 `.keras` 파일을 직접 실행하지 않습니다. TensorFlow.js Layers 형식으로 변환하면 구조를 담은 `model.json`과 숫자 가중치를 담은 `.bin`이 생성됩니다.

이번 변환에서 중요한 성공 원칙은 세 가지입니다.

1. Colab 기본 Python 3.13을 건드리지 않고 Python 3.11 가상환경을 사용합니다.
2. 데이터 증강을 제외한 표준 추론 모델을 다시 만듭니다.
3. 원본과 새 모델의 예측 차이가 `0.0000000000`인지 확인한 뒤 변환합니다.

변환은 모델을 다시 학습하는 과정이 아닙니다. 같은 구조와 가중치를 브라우저가 읽을 수 있는 파일 형식으로 바꾸는 과정입니다.
