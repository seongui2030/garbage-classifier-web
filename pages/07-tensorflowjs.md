# 06. 모델 평가와 일반화

테스트 정확도는 약 `0.7595`, 즉 75.95%였습니다. 이것은 테스트 이미지 전체에서 맞힌 비율이며 모든 클래스가 같은 성능이라는 뜻은 아닙니다. 또한 Kaggle과 비슷한 사진에서의 성능이지, 모든 실제 촬영 상황의 성능을 보장하지 않습니다.

일반화란 학습 때 보지 못한 새로운 상황에서도 규칙을 적용하는 능력입니다. 휴대폰 사진은 배경, 조명, 그림자, 거리, 각도, 카메라 후처리가 달라 도메인 차이가 생깁니다. 따라서 데이터셋 내부 테스트와 실제 휴대폰 테스트를 모두 수행합니다.

평가는 숫자를 자랑하는 과정이 아니라 모델의 약점을 발견하는 과정입니다. 틀린 사진을 모아 원인을 분류하고 다음 데이터 수집 계획으로 연결합니다.
