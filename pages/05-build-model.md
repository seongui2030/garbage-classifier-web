# 01. 프로젝트 시작하기

## 학습 목표

- 이미지 분류 프로젝트의 입력, 처리, 출력을 구분할 수 있습니다.
- ‘모델 만들기’와 ‘웹앱 만들기’가 서로 다른 단계임을 설명할 수 있습니다.
- 프로젝트를 작은 성공 단계로 나누어 계획할 수 있습니다.

쓰레기 분류 앱의 입력은 사진입니다. 처리 과정은 CNN이 사진의 특징을 계산하는 과정입니다. 출력은 `배터리 72%`, `금속 18%`처럼 클래스별 확률입니다. 한 장의 사진을 받는 단순한 앱처럼 보이지만, 그 안에는 데이터 수집, 정리, 학습, 평가, 변환, 웹 개발, 배포라는 여러 단계가 들어 있습니다.

이 프로젝트에서는 결과만 복사하지 않습니다. 각 단계에서 작은 검사를 수행합니다. 예를 들어 데이터 폴더를 만들면 클래스별 파일 수를 출력하고, 모델을 만들면 입력과 출력 형태를 확인하며, 웹 모델을 만들면 원본 모델과 예측값의 최대 차이를 계산합니다. 이 습관은 인공지능 개발에서 매우 중요합니다.

## 핵심 개념

```text
데이터 → 전처리 → 학습 → 평가 → 변환 → 웹앱 → 배포
```

각 화살표에는 ‘검사’가 들어갑니다. 데이터가 잘못되면 복잡한 CNN도 올바르게 학습할 수 없습니다. 웹앱 코드가 좋아도 라벨 순서가 틀리면 전혀 다른 이름을 출력합니다. 따라서 가장 먼저 속도를 내기보다, 각 단계에서 무엇을 확인할지 정해야 합니다.

## 생각 열기

1. 투명한 플라스틱 컵과 유리컵은 어떤 특징으로 구분할 수 있을까요?
2. 사진 배경이 분류 결과에 영향을 줄 수 있을까요?
3. 최고 확률이 35%라면 앱은 어떤 안내를 해야 할까요?

## 이번 장의 성공 기준

- 프로젝트의 전체 흐름을 자신의 말로 설명합니다.
- 10개 클래스를 정확한 모델 순서로 기록합니다.
- 낮은 신뢰도를 정답이 아니라 불확실성으로 해석합니다.
