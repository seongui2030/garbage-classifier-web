# 부록 B. 용어 사전

| 용어 | 쉬운 뜻 |
|---|---|
| 픽셀 | 디지털 이미지를 이루는 가장 작은 색 점 |
| 채널 | RGB처럼 색 정보를 나누어 담는 축 |
| 라벨 | 이미지에 붙인 정답 범주 |
| 클래스 | 모델이 구분해야 할 범주 |
| 배치 | 한 번의 계산에 함께 넣는 데이터 묶음 |
| epoch | 전체 훈련 데이터를 한 차례 학습한 것 |
| 합성곱 | 작은 필터로 주변 픽셀 패턴을 계산하는 연산 |
| 필터/커널 | 특정 무늬를 찾도록 학습되는 작은 숫자판 |
| 특성 맵 | 필터가 찾아낸 특징의 위치와 강도를 담은 배열 |
| 스트라이드 | 필터가 한 번에 이동하는 칸 수 |
| 패딩 | 출력 크기와 테두리 정보를 조절하기 위해 둘레를 채우는 것 |
| ReLU | 음수는 0으로, 양수는 유지하는 활성화 함수 |
| 풀링 | 중요한 특징을 남기며 가로·세로 크기를 줄이는 연산 |
| 손실 | 예측과 정답의 차이를 나타내는 학습용 수치 |
| 정확도 | 전체 중 맞힌 비율 |
| 정밀도 | 해당 클래스라고 예측한 것 중 실제로 맞은 비율 |
| 재현율 | 실제 해당 클래스 중 모델이 찾아낸 비율 |
| 과대적합 | 훈련 데이터에는 강하지만 새 데이터에는 약한 상태 |
| 일반화 | 처음 보는 데이터에서도 배운 규칙을 적용하는 능력 |
| 전이학습 | 큰 데이터로 미리 학습한 특징을 새 문제에 활용하는 방법 |
