# 11-2. 수행평가 루브릭

| 평가 요소 | 상 | 중 | 하 |
|---|---|---|---|
| 데이터와 윤리 | 출처·라벨·편향·개인정보를 근거와 함께 점검 | 출처와 클래스 수를 기록 | 데이터 설명이 부족 |
| 전처리 | 학습·서비스 전처리 일치를 코드와 shape로 검증 | 리사이즈와 정규화를 적용 | 입력 형태가 불명확 |
| 모델·평가 | 구조를 설명하고 클래스별 성능과 일반화를 분석 | 학습과 전체 정확도를 제시 | 실행 결과만 제시 |
| 웹앱 | 모델 로딩, 촬영, 전처리, 전체 확률, 오류 안내 구현 | 사진 한 장과 최고 클래스 구현 | 핵심 기능 미완성 |
| 문제 해결 | 오류의 원인·수정·재검사를 구체적으로 기록 | 주요 오류와 해결 기록 | 오류 기록이 모호 |
| 협업·발표 | 역할과 기여가 명확하고 한계를 정직하게 설명 | 결과와 역할을 설명 | 과정 설명 부족 |

## 평가 유의사항

1. 테스트 정확도만으로 높은 점수를 주지 않습니다.
2. 외부 코드는 출처와 이해한 설명이 있어야 합니다.
3. 다른 팀의 모델을 그대로 제출하지 않게 중간 기록을 확인합니다.
4. 낮은 신뢰도와 실패 사례를 숨기지 않은 분석을 긍정적으로 평가합니다.
5. 모델 파일보다 데이터 처리와 평가 근거를 함께 확인합니다.
6. 웹 디자인보다 핵심 기능의 정확성과 접근성을 우선합니다.
